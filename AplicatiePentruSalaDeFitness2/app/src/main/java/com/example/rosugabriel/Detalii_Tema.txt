Aplicatie pentru sala de fitness - Rosu Gabriel 1089-D



Gym, Membership - clase pentru a organiza si manipula datele despre sali si abonamente

LoginActivity - este activitatea unde utilizatorul introduce datele (email, pincode) pentru conectare
                daca acesta are cont deja

              - daca nu, acesta poate apasa pe butonul "Become Member" unde se va duce in activitatea
                BecomeMemberActivity

              - acesta poate introduce datele de conectare, care sunt validate prin expresii regulate

              - daca datele sunt valide se va duce in activitatea BecomeMemberActivity


BecomeMemberActivity - este activitatea unde utilizatorul poate selecta orasul in care doreste
                       sa isi faca abonamentul

                     - selectia orasului se face printr-un element de tip Spinner

                     - la selectia orasului sunt afisate salile din acele orase, aceasta avand
                       afisate o poza, inlocuita cu un placeholder default pentru toate salile,
                       respectiv ic_gym_placeholder.xml din directorul res/drawable/
                       detalii precum programul, adresa, facilitatile salii si numarul de telefon

                     - utilizatorul poate apasa butonul "Detalii" pentru a vedea detalii legate
                       de sala sau pe butonul "Choose" pentru a-si face abonament la sala respectiva

                     - salile sunt afisate intr-un RecyclerView pentru a permite afisarea unor machete
                       mai complexe, acestea continand si un element de tip ImageView

                     - in directorul layout din directorul res se afla macheta unui astfel de element
                       din interfata de tip "gym" in gym_item.xml

                     - pentru a lega datele salii adaugate in cod din BecomeMemberActivity de elementele
                       din interfata din RecyclerView am creat un adapter personalizat "GymAdapter"

                     - acesta are un ViewHolder personalizat pentru a putea stoca in View elementele
                       de tip ImageView, TextView

RegisterActivity - este activitatea unde utilizatorul se inregistreaza, dupa ce isi trece datele in formular
                   se trece la activitatea AccountCreatedActivity.

AccountCreatedActivity - este activitatea unde sunt afisate datele de conectare ale utilizatorului,
                         are un meniu din care poate selecta optiunile "Despre" sau "Logout"
                         si un FloatingActionButton cu care poate interactiona

GymAdapter - este o clasa care extinde RecyclerView.Adapter cu un ViewHolder personalizat GymViewHolder

           - aceasta permite legarea datelor salilor de elementele vizuale din RecyclerView

           - a fost creat pentru a putea afisa elemente complexe in RecyclerView, elementele avand
             asociate poze

           - inauntrul clasei este definita clasa GymViewHolder care extinde RecyclerViewHolder
             pentru a tine referinte catre elementele de interfata(View) din RecyclerView

                - clasa GymViewHolder implementeaza metodele OnCreateViewHolder este apelata
                  de RecyclerView atunci cand are nevoie de un nou ViewHolder pentru a afisa
                  un obiect de tip gym si OnBindViewHolder
